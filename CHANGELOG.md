# Quantum Guard Changelog

This repository tracks public Quantum Guard release milestones.

## 1.7.0 — Development Preview

**Channel:** Prerelease  
**Platform:** Windows x64

### Included in the public preview

* Application protection controls
* Focus controls
* Scheduling and after-hours features
* Web protection direction
* Download Guard direction
* Cloud and multi-device management groundwork

### Development work following this preview

The active development roadmap includes:

* Google-authenticated cloud profiles
* Organization and device enrollment
* Pairing-code reliability
* Administrator and client device roles
* Profile synchronization between devices
* Device heartbeat and active-user status
* Account suspension and blocking
* Remote policy assignment
* Managed software updates
* UI scaling and rendering hardening

### Important

This build is a development preview and should be tested on a non-critical Windows device before wider deployment.

For downloads and checksums, use the official GitHub Releases page.
