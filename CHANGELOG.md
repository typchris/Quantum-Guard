# Quantum Guard Changelog

This repository tracks public Quantum Guard release milestones and active development previews.

## 1.9.0 — Integrated Preview (not yet published)

**Status:** Windows QA candidate  
**Platform:** Windows x64

### Integrated development work

* Device-specific Owner, Admin and Client roles
* Roaming Google/Supabase profile context
* Managed Client UI restrictions backed by Supabase authorization
* 60-second device heartbeat and active-user status
* Pairing-code display and enrollment flow improvements
* Remote device-command polling
* Account Active, Suspended and Blocked control groundwork
* Administrator audit logging
* Built-in GitHub update notification and background download flow
* Verified SHA-256 release metadata and updater rollback support
* Cloud status repainting for the reported overlapping-status-text problem

### Release note

The 1.9.0 integrated build is being validated separately and is not announced by the public update feed yet. The public feed remains on the last actually published executable until a matching GitHub Release is published and verified.

## 1.7.0 — Development Preview

**Channel:** Prerelease  
**Platform:** Windows x64

### Included in the public preview

* Application protection controls
* Focus controls
* Scheduling and after-hours features
* Web protection direction
* Download Guard direction
* Cloud and multi-device management groundwork

### Development work following this preview

The active development roadmap includes:

* Google-authenticated cloud profiles
* Organization and device enrollment
* Pairing-code reliability
* Administrator and client device roles
* Profile synchronization between devices
* Device heartbeat and active-user status
* Account suspension and blocking
* Remote policy assignment
* Managed software updates
* UI scaling and rendering hardening

### Important

This build is a development preview and should be tested on a non-critical Windows device before wider deployment.

For downloads and checksums, use the official GitHub Releases page.
