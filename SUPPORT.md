# Quantum Guard Support

Quantum Guard is currently a development preview.

## Before reporting a problem

Please record:

* Quantum Guard version
* Windows version
* display scaling percentage
* whether the window was maximized
* exact steps that reproduce the problem
* a screenshot if the issue is visual

## Useful report categories

* User interface and scaling
* Application protection
* Focus mode
* Schedules
* After hours access
* Web protection
* Download Guard
* Cloud sign in
* Organization enrollment
* Pairing codes
* Device synchronization
* Updates

If you have access to the private repository, use the GitHub issue templates when possible. Do not place secrets, OAuth codes, API tokens, private report URLs, or signing material in issue text or screenshots.
