# Quantum Guard 1.9.0 — Integrated Preview

**Release type:** Prerelease  
**Platform:** Windows x64  
**Status:** Windows QA candidate

## Highlights

- Device-specific Owner, Admin and Client roles
- Google/Supabase profile synchronization
- 60-second device heartbeat and active-user status
- Pairing-code and enrollment improvements
- Remote device-command polling
- Account Active, Suspended and Blocked control groundwork
- Administrator audit logging
- Built-in GitHub update notification and background download flow
- SHA-256 verified update metadata and rollback support
- Cloud status repaint fix for overlapping status text

## Important

This is an integrated preview and still requires live Windows QA before broad deployment. Test Google sign-in, DPI/scaling, pairing between real PCs, Admin versus Client UI behavior, remote account controls, tray notifications, Windows Defender/UAC interaction, updater replacement, watchdog handoff and rollback.
